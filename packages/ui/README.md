# @bram-van-osta/ui

The Bram van Osta React components, on Base UI's primitives, styled with Tailwind 4 on [`@bram-van-osta/tokens`](../tokens). No component yet: the first ones come with the base components.

## Using

React 19 and `@base-ui/react` 1.9 are peer dependencies. In the app's stylesheet, after Tailwind:

```css
@import 'tailwindcss';
@import '@bram-van-osta/ui/styles.css';
```

It brings the tokens as the theme, the fonts, and the components' classes for the app's build to generate.
